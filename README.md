# 像素秘境 · PIXEL ROGUE

单文件像素风动作割草肉鸽网页游戏。零依赖、无需构建——克隆后直接用浏览器打开 `index.html` 即可游玩。

## 玩法
- WASD / 方向键移动，攻击全自动
- 清完每波配额的敌人进入休整：吸收经验球 → 选择天赋 → 天赋置换 → 开启下一波
- 升级三选一天赋（34 种，普通/稀有/史诗/传奇四档稀有度），构筑专属 Build
- 怪物：史莱姆 / 蝙蝠 / 坦克 / 独眼射手（远程）/ 自爆虫，每 4 波出现精英

## 操作
| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 空格 | 冲刺（需天赋解锁，支持多段充能） |
| C | 属性面板 |
| P | 暂停 |
| M | 静音 |

## 技术要点
- 纯 Vanilla JS + Canvas，单 HTML 文件
- 程序化像素精灵（零外部图片）、WebAudio 合成芯片音效
- 天赋置换 = 卡换卡熔炉：2 张低稀有度卡随机熔出 1 张高稀有度卡
