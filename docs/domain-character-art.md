### 跑动修订 v2（2026-11-01）

用户反馈跑步姿势奇怪。原源表的前倾、宽步幅与相近的前后脚姿势使循环读起来像单侧蹬跳；运行时纯纵向移动又会在部署时被索敌方向带动转身。

- 用内置 imagegen 整表编辑左右两向各一张 4×4 源图，第一行为尺度参照，其余三行分别替换 run / run-deploy / run-collapse，合计 24 帧。B 的半面具、领片、短袍和独立封印牌保留；未改其他动作，旧版图集/记录/GIF 与未选源稿都保留。
- 新姿势采用较直的躯干、较低的抬膝和收敛的步幅。整组共用尺度，不逐帧缩放；X 改用上半身稳定锚点，避免随伸脚造成水平摆动，脚底 Y 仍为 59。当前全表可见高度 19–26px；原 40 帧与牌的像素哈希不变。
- 跑动每移动 8px 前进一帧（旧为 7px），三个移动动作保留同一相位；冲刺位移不推进跑步循环。纯纵向移动保留朝向，停下后才允许部署索敌改变朝向。移动速度、碰撞和技能计时不变。
- [新旧跑动对比](../assets/characters/domain/warden-run-v2-comparison.gif)：V1/V2 各展示左右两向和三种移动动作，按基础移速的实际步频回放，4 秒；属于离线素材对比，不是实战录像。正式人物图集已更新，游戏页需刷新重新加载贴图。

## 来源与归一化

使用内置 imagegen：从 B 概念编辑出身体种子，将三枚牌拆成独立 prop，再分别整表生成右向基础/技能、左向基础/技能四张 4×4 源表。没有逐帧独立生成。辅助编辑画布按 sprite-pipeline 构建，原始源表与完整提示词均保留。

模型返回源图尺寸以检查记录为准，不假定提示词尺寸。源表行列有偏移，按透明间隔分组，保留完整人物；所有源表使用一个参考尺度（按整表尺寸比例换算），预乘 alpha 面积采样、现有色板 Lab 最近色、二值 alpha，按下部靴子区域平移到固定脚底锚点。没有覆盖其他人物资产或修改 palette.ts。

封印牌单独生成与量化，正式表现读取模拟时间作轻微浮动；暂停/属性冻结时装饰与身体一起冻结，不增加表现 RNG、输入监听或另一条运行时 RAF。

## 动作接线口径

| 动作 | 实际状态来源 |
|---|---|
| idle / run | 固定步后的真实位移，纯纵向保留朝向，撞墙不原地跑 |
| deploy | 领域武器自己的 0.25 秒部署状态，不读取传统 MageSystem 充能或站定 |
| run-deploy | 部署期间仍有真实移动；优先保持腿部步态，不能用动画冻结玩家 |
| collapse | 本轮真实收拢阶段及进度，手势不改变黑洞形成/伤害时刻 |
| run-collapse | 收拢时仍有真实移动，保持完整移动能力 |
| dash | 真实冲刺余时，不新增冲刺距离或冷却 |
| hurt | 真实受击事件的短暂表现，不伪造受伤或额外硬直 |

身体、角色装饰和位移残影共用一致姿态。Scene 只读 Core 状态，角色表现不反写规则；加载失败保持原人物回退。
