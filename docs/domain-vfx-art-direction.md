## 视觉方向：墨紫结界与空间剪切

- 借鉴的是领域展开的压迫感、空间被切开/折叠的意象，以及静态积蓄后骤然收紧的节奏。使用原创抽象封印碎片，不包含作品角色、标志或具体场景。
- 主体是墨黑空间裂隙与紫色结界，青白高光只沿能量边缘游走。普通领域保持中空，装饰集中在外环；黑洞有明确的暗核与三股向心旋流，形成时追加不对称 X 形空间剪切。
- 亮度高潮集中在黑洞形成后的 0.24 秒视觉余波，伤害仍应在形成瞬间结算；不用填满画面的白色圆盘，不用红橙色敌方危险圈。
- 层级为地面结界/黑洞底层 → 敌人 → 短促剪切高光/控制标记 → 伤害文字。黑洞稳定期保留单位轮廓与攻击提示，爆发只短暂跨到前景。
- 领域值提高效果强度时，可增加细流密度、封印节点亮度和剪切边缘层次；半径、实体持续与施法节拍仍读取各自真实数据，不能用视觉强化假装扩大判定。

## L3 与生存表现语言

| 机制 | 造型与动效方向 | 可读性边界 |
|---|---|---|
| 无量空处 | 约0.32s展开黑蓝深空，星点/偏心透视环与青白边界替换普通领域内部纹样；信息碎片汇入每个目标，实际过载时收为静止的白青轮廓/认知锁 | 过载期间暂停自主行动及领域牵引，恢复后继续吸入、清除锁；Boss免硬控不画假锁。场景与状态分开，地面预警仍画在其上；黑洞继续保留原暗核纹理 |
| 连续空间斩 | 按用户明确选择，恢复每个受击怪物身上连续出刀：0.1s一轮，实际命中产生0.09s短斜斩，紫色刃沿/骨白刀芯、尖端掠过身体、左右斜向交替；长度随目标体型，半长10–24px | 全域判定不限目标数，同目标同轮一刀，命中被阻止时不画假刀；刀痕跟随存活目标、击杀刀停留于死亡位置。数字0.3s聚合，收拢继续攻击真实缩圈内目标，不再向空处分散装饰刀痕 |
| 禁锢 | 目标外侧四个折角空间锚，收拢开始时短促扣合 | 不画遮住身体的实心锁链；外力牵引仍可见，不能把定身表现成禁止所有位移 |
| 引力护盾 | 角色外侧两道错位紫色护弧与细断环 | 不用黑洞暗核替代盾，不挡角色朝向或生命条 |
| 质量虹吸 | 从实际受伤目标方向抽出少量细线，汇入角色后消散 | 按一次合法回复事件触发，不按跳伤反复刷绿字或连线 |
| 奇点步 | 冲刺起点留下短暂小涡流，稀疏碎片向心收束 | 与普通领域有明确尺寸/纹样差别，不计入三领域视觉格数 |

当前预览演示前三项的几何造型，护盾/虹吸/冲刺独立素材尚未制作。
