## 1. 用户最新方向

- 普通领域承担主要输出，第一片领域就应能独立打怪。
- 黑洞作为类似强化弹的周期强化奖励，取消三个场同时存在、再合成才能打主要伤害的门槛。
- 斩击作用于整个领域空间，不能只挑三只敌人补刀。
- 无量空处需依据作品的核心概念重设计，不能只把短眩晕拼成被动。
- 已确认选择：**同一个领域叠加空间斩击与信息过载**，两者共存；黑洞在此之外提供强化奖励。
- B 结界执律者、已认可跑动 v2、封印牌、墨紫结界/黑洞造型、数字字形和已认可声音保留。重新编排表现的时机与区域覆盖，不重新发散人物身份。

## 2. 调研：参考概念与游戏改编分开

### 无量空处

ABEMA 对动画第 7 话的回顾描述了信息持续灌入、感知无法完成而使目标不能行动的效果。关键体验是认知过载与行动失效；引力吸附、持续伤害或小眩晕脉冲本身不能代表这个概念。

来源：[ABEMA：五条首次无量空处场景回顾](https://times.abema.tv/articles/-/10168180?page=1)。

游戏化建议：同一领域持续产生输出，同时对域内敌人进行信息灌注，进入一段清晰连续的过载停滞窗口。停滞时普通目标不能自主移动或攻击，领域攻击继续生效。对象恢复后用明确抗性/免疫状态控制重复压制；不能依靠视觉表现掩盖实际已免疫的控制。

这是本游戏的改编建议，不声称原作有固定数值、伤害公式或本项目的控制递减。现有普通怪单次 1.2s 上限、精英半效、Boss 硬控免疫和共享递减/免疫窗口应随新版控制周期一起复核；重叠领域不能刷新为无限控制。

### 领域内空间斩击

ABEMA 对伏魔御厨子的介绍强调效力范围内持续发生的斩击。可借鉴的是区域攻击与持续压迫的组织方式，不是给少数选中目标播放刀光。

来源：[ABEMA：领域展开介绍，伏魔御厨子段落](https://times.abema.tv/articles/-/8673215)。

本游戏采用原创墨紫空间裁切：领域内部产生横向、纵向、对角线等贯穿断面，当轮判定覆盖整个领域。视觉线条只是全域攻击的表现，不作为额外伤害条数；不要求刀线实际划过敌人才结算，也不把普通领域伤害变成随机选三个目标。

## 3. 当前 v1 为什么出伤慢

代码入口：`data/domain.ts`、`data/combatBalance.ts`、`core/DomainSystem.ts`、`core/DamageMath.ts`。

| 当前环节 | 实际问题 |
|---|---|
| 部署 0.25s，落地后再等 0.25s 跳伤 | 起手约 0.5s 才首次扣血，普通领域缺少落地首击 |
| 普通域 0.2D / 0.25s | 基础只有 0.8D/s，承担主输出能力不足 |
| 斩击与无量的旧代价相乘 | 两升级齐备后，普通域跳伤降到 0.612D/s；给能力升级附加了削弱主输出的负担 |
| 第三个场落地即进入收拢 | 第三个领域自身几乎没有持续输出机会，已有场提前停止跳伤并被消耗 |
| 黑洞在第三次部署后再等 0.35s | 基础理想节拍下约 2.4s 才出现集中爆发，普通攻击变成等待奖励的铺垫 |
| 每域最多斩击三目标 | 大群敌人在领域中也可能没被斩到，规则和空间斩击表现不一致 |
| 升级大量分配给黑洞半径/持续/牵引 | 主要强化后半段；把能力移到 Lv.2/3 只改变取得时机，没有修复输出结构 |

以 D=11、M=1、护甲 25 为单纯算术示例：旧普通领域每跳约 1.47，取得两能力后约 1.12。这里不包含斩击、重叠、暴击、天赋或动态难度，不是整局 DPS 对照。

## 4. 新攻击循环

建议循环：

`普通展开 → 普通展开 → 普通展开 → 强化展开（额外黑洞） → 循环`

- 每次对施法范围内最近的合法敌人选点，保留短提前量与落地固定规则。
- 普通领域短起手后立即打出一次全域首击，随后继续全域攻击，吸入途中与到中心后均有效。
- 已有领域按自身寿命输出，不为了黑洞提前消失。生成黑洞不暂停新的普通施放。
- 每次成功部署推进一次刻印；第四次部署触发额外黑洞，不依赖旧领域是否还活着、是否重叠、是否已有足够目标被捕获。
- 一次部署只记一次刻印，多个目标和多条斩线不多记；无目标不空刷，派生/回响领域不刷刻印或武器经验。
- 三枚封印牌可作为前三次刻印的可视积累，强化展开时向黑洞集中，保留已认可的收拢视觉语言。
- 黑洞仍有独立的集中爆发、短暂牵引和收尾；无黑洞的时间，领域也应有完整输出能力。

强化计数建议为四次，与当前射手强化弹的循环相近；目前是方案建议，不是已经接入的计数值。

## 5. 同域双机制

### 空间斩击承担主要输出

- 展开首击与持续裁切具有明确节拍，整个圆形领域均为有效攻击范围。
- 每轮所有合法目标各结算一次，不保留三目标上限。
- 多条切线、十字交点、同一目标跨过数条线，都不会让同一轮重复扣血。
- 首尾裁切可以有更强反馈，普通连续切割保持清楚的群体节奏；不再只在敌人身上逐个画短刀痕。
- 斩击升级要改变主输出形态/节奏，不以降低普通领域伤害来交换少数补刀。

### 无量空处提供信息过载压制

- 领域成型后，域内目标接受连续的信息灌注。
- 形成过载时给出一段稳定、连续、看得清的失能窗口；空间斩击与领域基础攻击照常进行。
- 目标表现为动作与攻击被压制、认知纹样累积和停滞，避免把主要反馈做成拉扯抖动或偶发转星。
- 保留“免疫/抗性期间仍受到正常领域伤害”的分离，Boss 的控制替代收益另定，不能把无量升级在 Boss 战中做成纯减伤代价。
- 精英/Boss 边界、灌注时间、停滞时长及共享递减具体节奏需要与新领域持续时间一起确定；原 v1 的零碎脉冲不作为默认基准。

两机制在同一领域共存，不做二选一专精或自动交替两种场。升级提供基本能力，天赋再改变额外互动。

## 6. 初步伤害预算示意（待讨论）

目标：稳定战斗中由普通领域贡献约 70%–80% 的主要伤害预算，黑洞约 20%–30%；这只是分工目标，实际伤害占比受覆盖、敌群/护甲/击杀和奖励频率影响。

| 项目 | 示例起点 | 目的 |
|---|---|---|
| 起手 | 约 0.15s | 领域展开即有首击，不再落地后空等第一跳 |
| 基础施放周期 | 约 0.7s | 普通出手足够频繁，攻速继续生效 |
| 单领域持续 | 约 1.2s | 输出集中、收尾清楚，延长升级体现为增加完整攻击轮次 |
| 展开首击 | 1.0D × M | 第一片领域就有明确的生命损失与数字 |
| 持续攻击 | 每 0.3s 0.4D × M，示例四轮 | 主体伤害持续来自领域自身 |
| 单场完整预算 | 2.6D × M | 基础攻击能独立处理标准小怪 |
| 强化奖励 | 每四次部署额外黑洞 | 奖励普通输出的持续展开，不替代普通输出 |

仅作理想预算分配演算：四个场完整命中为 10.4D；若黑洞示意预算为 4D，则领域部分约 72.2%。未计重叠衰减、目标提前死亡/离场、护甲/暴击/天赋，不能当作同一目标实际循环伤害或新平衡结论。

同一基准 D=11、M=1、目标护甲25下，单场 2.6D 完整命中约 19.07 伤害。这里只用来检查“没有黑洞也有完整杀伤”这一方向，正式系数需要用真实波次的小怪、精英和 Boss 分别校准。

活动领域数量、重叠结算、攻速增益与持续升级的收益必须一起校核：不能因旧场被替换而使延长升级无效，也不能因多个场同时攻击而多刷强化计数。该项尚未定稿。

## 7. 升级与天赋重新分工

武器升级稳定完成主玩法，暂不把旧十一项全部照搬。优先确定显著改变行为的成长：全域空间裁切、信息过载、额外完整攻击轮次、强化轮全场共鸣、黑洞终末裁切等。半径/持续等基础成长可以保留，但不能占据大半成长体验；持续直接以“多几轮攻击”展示。

天赋提供可选互动，以下为候选，不是已确认卡表：

| 候选机制 | 希望形成的取舍/变化 |
|---|---|
| 断层回斩 | 每若干轮裁切追加一次反向全域斩，派生不刷刻印/经验或递归触发 |
| 信息回响 | 过载结束产生一次认知余波或后续攻击窗口，需同时设计控制免疫边界 |
| 残界追击 | 场自然结束后，在最近存活目标处补一次收尾裁切，不凭空续出整片新主场 |
| 质量回收 | 主领域击杀反馈下一次展开节奏，收益早于黑洞，设每次施放的返还上限 |
| 引力护盾 | 主领域的真实命中/群体攻击即可提供受限防护，不再等三场合成 |
| 质量虹吸 | 主领域的实际 HP 损失或击杀参与受限恢复，不能靠群怪数量无限回血 |
| 回响刻印 | 达成明确的群体攻击条件时额外推进一次强化进度，每次展开有上限 |
| 迁界 | 冲刺与已有领域位置联动，改变覆盖方式，不重置寿命/首击或刷刻印 |

先验证这些行为是否有辨识度，再确定卡数、等级门槛与系数；不把“斩击 +25% / 眩晕目标 +20%”作为本次重做的主要交付。

## 8. 本次需要通过的体验目标

- 首个普通领域就能看见明显输出，标准小怪可由普通领域独立解决。
- 即使一段时间没有触发黑洞，武器仍然完整、有连续杀伤。
- 领域内超过三个目标时，仍能同时看到整域裁切的伤害反馈。
- 无量开启后有连续的信息过载压制窗口；恢复/免疫状态也清楚，不假装永久失能。
- 黑洞触发不吞掉普通领域、不中断主输出；强化计数不依赖三个领域同时活着。
- 升级和天赋至少有数项能从攻击轮次、区域覆盖、强化循环和互动中看出变化。
- 已认可美术沿用；新时间编排和全域切割覆盖需要独立检查，不能仅靠编译通过宣称体验达标。
