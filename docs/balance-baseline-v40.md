# 基线快照 v40（伤害重做的尺子）

> **用途**：换掉整张天赋表之前先留一把尺子。之后任何一批改动都能回答「变强还是变弱」，而不是靠体感。
>
> **机器基线**：`tests/fixtures/balance-baseline.json`（由 `tests/balance-baseline.test.ts` 生成并守护）。
>
> **重新生成**：`UPDATE_BALANCE_BASELINE=1 npx vitest run tests/balance-baseline.test.ts`
> —— 改基线必须在提交信息里写明「基线更新依据」，否则等于偷偷改尺子。

---

## 1. 记录了什么

| 区块 | 内容 |
|---|---|
| `playerBase` | 未学任何天赋时的**全部静态数值**（44 个字段，含 `typeDamageBonus.fire` 这类映射型）+ 两个派生指标 |
| `talents[name]` | 学 **1 级** 与 **满级** 后相对 base 的**增量**（只记变了的字段）+ 指标比值 |
| `enemyPressure` | 标准怪（slime）在波 1/5/10/15/20/25/30 的单怪 HP、伤害、配额、总压力倍数 |

排除的运行态字段（会随帧变）：位置、`hp`、`fireCd`、`shield`、`shieldCd`、`dashT/dashRe/dashCharges`、`haste/hasteT/rageT`、`tempShield`、`ndUsed`、`orbA`、`hurtCd`、`meteorT`、`lvl/xp/xpNext`。

## 2. 两个派生指标（参考口径，不是权威公式）

```
coverage = (1 + pierce) × multishot
critExp  = 1 + min(1, critChance) × (critMultiplier - 1)
dpsIndex = attack × boltDmgMul × fireRate × critExp × (1 + global) × coverage
ehpIndex = maxhp ÷ [(1 − 护甲减伤) × (1 − 韧性) × (1 − min(0.6, dodge))]
           护甲减伤 = 1 − K/(K+DEF)，K = combatBalance.armorK，韧性夹 0..0.6
```

**三条已知局限**（写在测试里，改口径必须同时改那段断言）：

1. 不含属性强化——当前系统还没有属性成长，所以**这些数不随波次变**；
2. 不含类型/形态条件增伤（按伤害类型生效，原样记录在 `indices.typeDamageBonus` / `formDamageBonus`，但不折进 dpsIndex）；
3. 不含元素/DoT/召唤/护盾/环绕飞刃等衍生伤害。

## 4. 快照跑出来最要紧的四件事

**① 单张「磨刃」拉满就能到 DPS ×12,527。**
`max: 99`、每级 `damage ×1.1` → 11 级伤害变成 **137,795**。这不是「叠了几张卡」的问题，是一张卡自己就是指数。同类：**强化弹丸 30 级 = ×1.25³⁰ = 807 倍**（正好对上讨论里那个 800 倍）。

**② 生命上限是加法，反而"安全"。**
生命之泉 99 级 = maxhp +1980（生效生命 ×20.8），巨人血脉 ×30.7。它们夸张，但**线性**——和 ① 不是一个量级的问题。

**③ 41 张里 27 张，这两个指标完全看不见。**
烈焰印记、雷霆连锁、星辰坠落、护盾、飞刃、闪避后、击杀后触发……这些卡满级后 `dpsIndex` 与 `ehpIndex` 一动不动。所以：

> **配平不能只靠静态指标。** 新表 58 张几乎全是不改变静态数值的机制卡，只会有更多「指标盲区」。S4 配平必须跑**模拟对局**统计伤害构成（谁的伤害占比多少），静态指标只能当兜底。

**④ 指标能看到的那 14 张，全是数值卡。**
强化弹丸、疾速扳机、生命之泉、分裂射击、穿透之矢、致命一击、会心深渊、磨刃、狂怒、毁灭本能、闪避本能、铁布衫、巨人血脉、磐石——**正好是附录 D 里判定「应迁属性系统」的那批**。指标看得见的都是纯数值，这条对应关系反过来印证了迁移判断是对的。

## 5. 换表之后怎么用这份基线

1. 旧卡退役前，先跑一遍新表，把同一批「指标可见」的卡与这里逐项对照（±10% 以内视为等价）；
2. 对 27 张盲区卡，改用「模拟一局 → 伤害构成 + 清场时间」对比，不用静态指标；
3. 每次大改后重跑一次，数值漂移超过预期就在 PR 里说明原因，不要顺手更新 JSON。
