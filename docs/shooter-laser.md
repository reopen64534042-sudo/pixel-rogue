# 射手激光主武器（v140）

当前实现连续切割束、聚焦核心链和独立多向的三联主束（草案 v134 替换棱镜，v135 改为独立索敌，正式交付统一为 v140）。数值为首版配置，编译与构建通过后仍需自然试玩确认强度、跟随速度、清场效率与画面遮挡。

## 玩家入口

开始游戏 → 射手 → 激光。强化弹与激光分别使用自己的武器等级、升级列表与职业天赋池。首次选择射手沿用职业教程，激光职业课改为保持远距并累计照射木桩 2 秒；教程内不获得武器经验。死亡后的按钮重开与 R 键均保留本局武器，返回开始界面可以重新选择。

激光自动锁定射程内最近目标；目标死亡或越界才重新索敌。角色可以完整移动与冲刺，束线基础每秒最多转向 8 弧度（v137 调整；180° 约 0.39 秒），稳束器与稳束扫描继续提供倍率。基础照射 1 秒、回充 0.3 秒、宽度 4px、射程沿用射手属性。主束贯穿全部实际相交的敌人，每穿过一个目标后保留 80% 伤害；命中按沿束距离排序。

## 两条确认规则的落点

1. **经验按主束有效照射时间累计**：最多 1 经验/秒，每个照射周期最多 1 经验。命中多个敌人不会加速；余辉、残像、收束脉冲和紧急散射均不给武器经验；获得三联后，任意主束有效照射均可累计，但三束仍共享同一份上限。储能电容延长照射，仍保留单周期上限。
2. **高频触发收益按时间控制**：主束照射按模拟时间积分，每 0.1 秒经统一伤害管线结算，周期结束也结清尾段；保留浮点，避免每次最少 1 点的额外增益。单目标每 0.4 秒掷一次暴击并复用结果，命中特效也只在这个窗口触发。主束吸血按实际 HP 损失、30% 效率计算，所有目标共享滚动一秒内最多 2% 最大生命的预算。附属束不暴击、不吸血、不触发命中特效或击杀爆炸；同一时段余辉 / 残像重叠只取单目标最高伤害。三条主束对同目标的原始伤害可以叠加，先合并再共用一个暴击 / 命中特效窗口。

单束基础 DPS = 攻击 × 原魔弹倍率 × 当前攻速（含狂热/战意）× 1.8 × [1 + (武器等级−1) × 0.08]。每轮开始固化攻击方快照及基础 DPS，当前帧实际照射时间、目标、贯穿与焦点决定本帧原始伤害。物理 / 远程属性仍经过 CombatSystem → DamageSystem，护甲、远程增伤和射手高波动态减伤照常生效。攻速提升 DPS，不缩短暴击、命中特效或经验的时间窗。

## 属性强化（v137）

- 攻击提高伤害基线；攻速在激光局显示为「光束输出」，并明确说明提高光束每秒伤害。仍使用原攻速属性与上限，回充 / 暴击 / 命中特效的时间窗独立。
- 功能格新增激光专属「光束宽度」，普通 / 稀有 / 史诗 / 传奇分别 +10% / +15% / +21% / +29%。只在射手且主武器为激光时进入候选，其他职业和强化弹不抽到。
- 宽度强化使用现有 area 属性模型，按来源累加百分比，再与扩束镜的 ×1.5 相乘。例如一张白卡使 4px 变为 4.4px，同时持有扩束镜为 6.6px；主束、残像、余辉和脉冲的几何 / 渲染共用该宽度。
- C 面板的输出速率按基础值显示倍率（初始 ×1.00），包含当前狂热 / 战意；「单束基础 DPS」为暴击、聚焦、增伤和防御结算之前的值。光束宽度另列实际 px。
- v136 已修复全局增伤属性卡，所有职业均可正常获得卡面增伤；本批沿用该修复。

初始 13 攻击 / 2.2 输出速率时，单束照射 DPS 为 51.48，按 1 秒照射 / 0.3 秒回充计算理想周期均值为 39.60。该配置算术不含聚焦、暴击、护甲、增伤与转向失准，不是实机 DPS 验收。

## 武器成长

共 12 级；升到下一级的有效照射经验依次为 5 / 9 / 14 / 20 / 27 / 35 / 44 / 54 / 65 / 77 / 90。Lv.4–12 每级从达到开放等级、尚未获得的升级中随机取得一条；最多 9 条，最终可以共存。

| 升级 | 最早等级 | 效果 |
|---|---|---|
| 扩束镜 | 4 | 所有主束宽度 +50% |
| 长焦镜 | 4 | 射程 +25% |
| 储能电容 | 4 | 照射 1 → 1.3 秒，单轮经验上限维持 1 |
| 快速回充 | 5 | 基础回充 0.3 → 0.2 秒 |
| 稳束器 | 5 | 转向速度 +35% |
| 余辉轨迹 | 5 | 每 0.15 秒留下存在 0.25 秒、20% DPS 的旧光路线段 |
| 透射镜 | 7 | 贯穿伤害保留 80% → 90% |
| 三联激光 | 10 | 三束各自锁定目标、独立转向，优先不同敌人，目标不足时可集火；每束 100% 伤害与完整射程，经验与触发预算共用 |
| 坍缩脉冲 | 11 | 每轮结束沿当前方向追加 80% 攻击的贯穿脉冲 |

三联仍占原来一条升级的位置，武器等级和升级总数不变。三束可以朝任意不同方向发射，各自持有目标、方向、焦点和脱离计时。先保留有效且互不重复的锁定，再分配未被占用的敌人；不足三只时允许集火，出现新目标后会拆开重复锁定。每束独立转向、检测贯穿 / 衰减，并按自身实际照射时间积累焦点；同目标不会因为多束而加快三倍聚焦，伤害仍可以叠加。余辉、折光残像和坍缩 / 熔断脉冲跟随当前束数；所有附属来源仍不给经验，不递归刷命中特效。未加入反射或独立脉冲炮模式。

## 专属天赋

14 张，全部 max=1；核心保留三层依赖。开局三选一保底包含「锁相」，其他升级仍按现有波次发放。

| 天赋 | 前置 | 作用 |
|---|---|---|
| 锁相 | 无 | 同目标照射 0.8 秒蓄满焦点，伤害逐步提高至 +50%；脱离宽限 0.15 秒，基础回充保留焦点 |
| 热穿 | 锁相 | 焦点 ≥75% 时，锁定目标之后的主束不再继续衰减 |
| 熔断 | 热穿 | 满焦点的周期结束释放 180% 攻击贯穿重脉冲，消耗焦点；与坍缩脉冲合并为同一次 260% 脉冲 |
| 猎手接力 | 锁相 | 主束击杀锁定目标，保留 60% 焦点给下一目标；其他来源击杀不触发 |
| 折光步 | 无 | 照射中成功冲刺，在原位置留下 0.3 秒、35% DPS 的旧方向残像 |
| 冷却滑行 | 无 | 回充中成功冲刺，剩余回充减半；每周期一次 |
| 远距校准 | 锁相 | 当前激光射程外 40% 区域内，焦点积累速度 +40% |
| 紧急散射 | 无 | 25px 内有敌人时，朝最近敌人扇形光冲：80% 攻击、18px 击退、3 秒冷却 |
| 稳束扫描 | 无 | 转向速度 +40% |
| 预热电池 | 锁相 | 脱离宽限延长至 0.4 秒 |
| 偏振穿透 | 无 | 每目标伤害保留额外 +5 个百分点，最高 95% |
| 光压退敌 | 无 | 主束命中特效窗口轻推目标，每目标最多每 0.4 秒一次 |
| 余能回收 | 无 | 主束每击杀缩短本轮回充 0.03 秒，每轮最多 0.15 秒，回充至少 0.05 秒 |
| 冷凝护甲 | 无 | 回充时受到的伤害降低 15% |

角色脚下青条表示照射 / 回充，细白条表示焦点（三联时拆为三小段），金条表示武器经验；C 面板分别显示主束 / 两副束的焦点。聚焦目标恢复蓝白到金色的圆环，真实焦点逐渐增强亮芯和锁定目标的命中热点；光束使用碰撞中心线与宽度，外层微光不扩大判定。C 面板显示等级、经验、DPS、范围、节奏、触发限制及已获得升级。伤害报告单列「激光」，图鉴标注「激光 · 槽位」，DEV 等级选择随当前武器切换。

## v140 正式动画

- 主束：默认使用已认可的透明图集与连续细束播放器；连续白芯、低对比纹理按模拟时间滚动，真实焦点控制强度，周期进度控制点亮 / 聚能 / 收束。
- 聚焦：圆环从上方随焦点逐渐画满，满焦点转金色，多束同目标只画最高焦点的一份；仅真实锁定命中点强化白热热点，其他贯穿点保持低强度。命中点由模拟只读提供。
- 三联：三条同宽、同强度主束各自朝锁定目标转向，发射口随各束方向布置在角色周围；三束分别使用实际碰撞中心线，切割火花沿各自方向散开。各目标独立显示聚焦刻度，多束锁定同一敌人时只显示一份。
- 余辉 / 折光步：余辉只留下变暗变细的旧光路，静止时隐藏与当前主束几乎重合的亮层；折光步在原位置显示淡色人物轮廓、旧发射口和逐渐退去的光束。伤害对象与寿命不变。
- 坍缩 / 熔断：首次闪出整条路径，亮头快速前进并留下消退的尾迹；坍缩用青白，熔断用更强的金白。两者仍在原结算时刻生效，不增加蓄力等待；三联状态下各束分别判断熔断：蓄满的束释放金白重脉冲并消耗自身焦点；坍缩仍随三束释放青白脉冲。重合目标的脉冲伤害合并结算。
- 紧急散射：同一次散射的三条表现线合画为展开的扇面、外推弧和三处短亮痕，沿用原扇形半径与角度。

正式 PNG、图集、元数据和用户确认的完整预览已随项目入库，来源与接入说明见 [激光动画素材包](laser-vfx-assets.md)。没有额外 RAF、计时器或表现随机数。动画只读 core.time / 阶段余时 / 效果寿命，暂停与属性冻结时保持静止。伤害飘字颜色与 v132 相同。

旧程序化回退预览：运行 node scripts/preview-laser-vfx.mjs，使用本机现有 Python / Pillow 与 Windows 微软雅黑，输出 output/laser-vfx-comparison.png、output/laser-vfx-preview.gif。它调用实际 LaserRenderer 绘制函数展示八种效果姿态，并生成四种效果的 20fps 原速动画；不是实机录像，也不执行战斗、伤害或浏览器验收。

## 维护入口与未验证项

- `src/game/data/laser.ts`：节奏、几何、经验表、升级和运行态类型。
- `src/game/data/combatBalance.ts` 的 LASER_DAMAGE、`core/DamageMath.ts`：伤害系数与纯公式。
- `core/LaserSystem.ts`：照射状态机、实际时间积分、结算窗口、成长、焦点、冲刺与附属光束。
- `data/talents/laser.ts`：卡面与依赖；机制读取 upCounts，不向 Player 塞临时运行态。
- `rendering/LaserRenderer.ts`：余辉 / 残像 / 散射、资源条与素材未就绪时的回退。
- `rendering/vfx/laser/`：正式动画播放器、只读桥接和 PixelPainter 接口；`GameScene` 默认加载并按固定步采集。

运行态保存在每个 GameCore 实例中，属性重算保留；暂停与属性面板冻结模拟，死亡 / 重开 / DEV 跳波与清天赋清理瞬态。战绩沿用原 v1 格式，只增加伤害分项，不改写旧记录。

按当前项目交付线只执行 typecheck / build，不运行 Vitest / Playwright，不新增或扩展测试、不修改 parity 基线。新增 laser 伤害键、14 张全局卡条目、射手武器选择步骤和激光运行状态会使旧完整快照、卡表总数、图鉴总数、开局直达射手及严格 parity 断言过期，留待用户授权的测试批次处理。跟随速度、焦点接力、自然波次强度、后期特效遮挡和实际性能尚待试玩。
