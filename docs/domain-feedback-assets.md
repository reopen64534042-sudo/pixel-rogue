## 专属“裂界数字”

字形为代码原生的 5×7 像素斩角数字，沿用当前像素文字体系与颜色语义，不生成模糊的 AI 字体。骨白字芯、墨紫外轮廓、紫色内边与左侧奇点菱形构成识别特征；出现时上/下半字形短暂错开，随后收紧停顿再上浮。真伤小号 `+N` 与主数字成组定位、共享运动，保留冷蓝真伤语义。

| 样式 | 稳定字形高度 | 生命周期 | 特征 |
|---|---:|---:|---|
| 普通坍缩 | 14px | 0.68s | 双描边、奇点菱形、短下划裂纹；未暴击也有专属样式 |
| 暴击坍缩 | 21px | 0.82s | 更大字形、三层轮廓与对角剪切标记，真伤附字不一起放大 |
| 引力斩击 | 7px | 0.32s | 小号紫色数字、轻描边，每目标每波次一个数字 |
| 终末爆发 | 14px | 0.48s | 中等骨白数字、收紧轮廓，优先级低于形成主爆发 |

- 形成数字前 55ms 允许 1px 错位，前 65ms 一档短促放大，约 140ms 后再上浮，末段淡出；不滚动篡改结算值，不把 0 伤害画成正数。
- 主伤害与生命压缩合并显示，真伤附字独立着色；暴击资格仍由伤害管线决定，数字样式不触发暴击，不借用强化弹 `specialHit`。
- 示例基准为 D=20、目标伤前 H=500、领域值 150、暴伤倍率 1.5、无其他修正：普通 `90 +12`、暴击 `120 +12`、普通领域斩击 `21`、终末 `24`。这只验证样式与示例算术，不是全 L3/满升级构筑的实际伤害。
- UI 真伤颜色从 `CombatSystem.ts` 的 `TRUE_DAMAGE_COLOR / TRUE_DAMAGE_OUTLINE` 读取；其他颜色从 `palette.ts` 读取，不另建与现有来源冲突的颜色真源。

数字产物位于 `assets/vfx/domain/numbers/`：

| 文件 | 内容 |
|---|---|
| `domain-glyph-mask.png` | 0–9 和 +，共 11 个白色透明字形；8×12 帧格，advance=6、baseline=9，供后续正式渲染适配 |
| `numbers.metadata.json` | 字形矩形、样式、字号、颜色来源、时长与示例 |
| `number-style-sheet.png` / `number-style-sheet-2x.png` | 四种样式的 1×/2× 检查图 |
| `number-motion-atlas.png` / `number-motion-3x.gif` | 108 个源采样帧与 3.6 秒动作展示 |

`domain-numbers.mjs` 是素材侧像素绘制器，包含 Node 文件读取，不得直接 import 到 Core 或浏览器生产入口；正式接线应消费字形 PNG/元数据，并沿用池化渲染。屏幕边缘与多目标聚集时还需在正式渲染层做整组避让，不改变每个敌人的真实结算或统计。

## 音效包与音色

位于 `assets/audio/domain/`，由现有 Python / NumPy / SciPy 原创合成：加法谐波、模态金属共振、带通噪声、反向包络与低频扫频叠层；无外部采样或人声。所有独立素材为 **48kHz / 16-bit / 立体声 PCM WAV**。

- **30 个技能/循环音效**：部署、连线、三域闭合、收拢、形成重击、黑洞/余烬循环、自然消散、终末、无量、三种斩击、禁锢、护盾生成/受击/破碎、加速、回收、碾压、绝对引力、回响、共振、聚焦、奇点步、虹吸、核心/理论层，以及暴击与真伤强调层。
- **15 个天赋获得提示**：每张卡独立文件、独立音高/时长组合，不把被动数值改变做成每跳重复鸣响。
- **9 个武器升级提示**：每条升级实际获得时一次；完整对应奇点半径、引力增幅、视界扩张、质量投射、领域延展、事件视界、奇点余烬、引力汇流、终末奇点。
- 另有 `domain-cycle-demo.wav`（6.2 秒组合音轨）和 `skill-showreel.wav`（7.62 秒主要技能串听），不计入 56 个独立音效。

完整的文件、种子、合成类别、时长、峰值/RMS、SHA-256、触发映射见 [audio-manifest.json](../assets/audio/domain/audio-manifest.json)。音色以“结界晶鸣 → 抽空吸气 → 低频重击与空间裂响 → 低亮旋流”为骨架，主爆发明显强于持续环境层。

## 混音、暂停与清理边界

- 黑洞形成声按每个黑洞一次，不按受伤敌人数播放；普通领域/黑洞持续跳伤无独立 tick 声。
- 建议全武器最多 8 个并发声部、最多 1 个黑洞环境循环、主事件最多叠 2 个修饰层。形成优先级 100、收拢 80、技能 60、环境 20；多种被动同时拥有时选取/合成音色层，不把所有文件同时叠满。
- 独立 WAV 有峰值/RMS 归一与渐入/渐出；黑洞/余烬循环使用周期波形和周期带限噪声，正式启动/停止仍应补约 12ms 增益过渡。
- 组合试听在形成与终末的瞬间降低次要声部，给重击让出空间；源文件与组合均保留余量，不把音量等同于领域值加成。
- 正式接线必须服从全局静音、暂停/属性冻结及清理入口。暂停时停止推进领域音效时间；收波/死亡/重开停止循环与待播事件，不能清理后补响终末或退款。
- 数字开关与声音开关独立。未来为避免通用受击 beep 叠加，应单独门控音频；不能为了关 beep 同时用静默选项吞掉专属数字，也不能绕过真实受击逻辑。

## 重建

```powershell
python assets/audio/domain/build-audio.py
node assets/vfx/domain/build-numbers.mjs
node assets/vfx/domain/build-preview.mjs --feedback
python assets/vfx/domain/export-preview.py --feedback
python assets/vfx/domain/export-feedback.py
```

使用已存在的 Node、Python、NumPy、SciPy、Pillow、PyAV 与 H.264/AAC 编码器，没有安装依赖或改全局环境。`preview-feedback.html` 以音轨时间为有声播放主时钟；静音时使用自身时间线，暂停/跳转同步音画，单独试听会暂停主预览。
