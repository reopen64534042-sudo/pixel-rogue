## 1. 目标

现有怪物以“接触、追击、自爆、网、冲锋、钻地、光环”为主，直接远程只有射手（直线弹），后期战斗的攻击方式仍偏单一。

本批补充：

- **3 种精英物种**：保留蛮牛精英，新增远程精英飞行眼魔、支援精英战鼓祭司。
- **3 种小怪**：熔岩投手（远程炮击）、晶甲虫（方向护盾近战）、缚电水母（持续光束远程）。
- 新攻击方式必须与现有怪不同；至少两种新远程，且每种都有明确预警与安全区。
- 不改变现有 10 种普通/特殊怪的数值与行为；不做新 Boss（Boss 见单独文档）。

## 4. 小怪设计

### 4.1 熔岩投手 `lobber`

**定位**：远程炮击，迫使玩家离开当前位置；与射手的即时弹丸、织网蛛的网区分。

| 项目 | 数值 |
|---|---|
| 生命 / 攻击 / 移速 | 30 / 14 / 32 |
| 半径 / 经验 | 5 / 2 |
| 护甲 | 18 |
| 抗性 | 火 55%、冰 -15% |
| 解锁 / 基础权重 | 15 / 8（实际权重见 §6） |
| 美术 | 16×16，熔岩虫 + 背部熔岩囊 |

**行为**

- 保持 180–260px；玩家 <140px 后退，>280px 靠近。
- 每 3.5 秒，若玩家在 280px 内：停止移动，0.8 秒预警，在玩家施放瞬间位置生成 R50 地面圆；结算时 1.0× 攻击火焰，并留下 R24 火焰地面 3 秒（0.25× 攻击 DPS）。
- 没有直线弹丸；全部是延迟地面判定，玩家移动即可躲开。
- 接触伤害按普通规则；不主动贴脸。

**与现有攻击的区别**：射手是即时直线弹，织网蛛是减速网；投手是“先落点、后爆炸”的炮击，且留下持续地面。

### 4.2 晶甲虫 `bulwark`

**定位**：方向性护盾近战，惩罚站桩正面输出，鼓励绕后/侧移。

| 项目 | 数值 |
|---|---|
| 生命 / 攻击 / 移速 | 55 / 12 / 28 |
| 半径 / 经验 | 6 / 3 |
| 护甲 | 45 |
| 抗性 | 冰 20%、火 -10% |
| 解锁 / 基础权重 | 16 / 6 |
| 美术 | 16×16，晶甲甲虫，正面盾壳 |

**行为**

- 缓慢追击；正面 120° 扇形内受到的伤害 ×0.4（60% 减伤）；背面/侧面正常。真实伤害无视护盾。
- 玩家在 110px 内时，每 4.5 秒发动 **晶刺突进**：0.6 秒直线预警（宽 30、长 110），随后前冲 80px，造成 1.0× 攻击物理伤害。
- 突进后的 0.8 秒护盾关闭（`guardDown`），是玩家的爆发窗口；之后恢复正面护盾。
- 不撞墙硬直、不击退玩家；难度来自“绕到侧面打”。

**与角兽的区别**：角兽是远程预警冲锋 + 撞墙硬直；晶甲虫是慢速、带方向护盾、短距突进，核心是站位。

### 4.3 缚电水母 `tether`

**定位**：持续光束远程，站桩惩罚；与射手的弹丸、投手的落点区分。

| 项目 | 数值 |
|---|---|
| 生命 / 攻击 / 移速 | 24 / 10 / 38 |
| 半径 / 经验 | 4 / 2 |
| 护甲 | 10 |
| 抗性 | 雷 40%、冰 -10% |
| 解锁 / 基础权重 | 19 / 8 |
| 美术 | 16×16，漂浮电水母 + 长触须 |

**行为**

- 保持 160–220px；玩家 <120px 后退。
- 每 5 秒，若玩家在 260px 内：0.8 秒直线预警（宽 20、长 240，锁定施放瞬间方向），随后持续 1.2 秒电浆束。
- 电浆束期间自身静止；每 0.3 秒检查玩家是否在光束带内，命中造成 0.3× 攻击雷电（最多 4 次）。玩家离开光束带即停止。
- 光束不追踪旋转；锁定方向，强调“横移出线”。
- 接触伤害按普通规则，但 AI 保持距离。

**与现有攻击的区别**：不是一次弹丸，也不是地面网；是持续通道伤害，站桩会被连续打，移动即安全。

## 5. 精英设计

### 5.1 精英物种与刷新槽位

保留 `brute_elite`，新增 `shooter_elite`、`drummer_elite`。

| 波次 | 精英数量 | 槽位物种 |
|---|---|---|
| 4、8 | 1 | 岩石巨兽 |
| 12–19 | 2 | 槽 1 岩石巨兽；槽 2 飞行眼魔 |
| 20+ | 3 | 岩石巨兽 / 飞行眼魔 / 战鼓祭司 |

- 物种按槽位固定，不额外消耗随机数；确保 W12 起每波至少有一只远程精英。
- 词缀仍从第 8 波起；精英物种与词缀独立。
- 同一波 3 只精英尽量不重复词缀；做不到时允许重复，但不能因此额外推进随机序列。
- 精英物种配置需要 `baseType`（`shooter_elite -> shooter`、`drummer_elite -> drummer`、`brute_elite -> brute`）。分裂词缀子体使用 `baseType` 生成非精英本体，避免子体错误继承精英贴图或精英基础数值。
- 精英专属配置可以放进 `ETYPES`，用 `w0=999 / wt=0` 阻止普通刷新；或放独立的 `ELITE_SPECIES` 表。实现时保持 Codex UI 能读取基础数值。

### 5.3 岩石巨兽（近战精英）

保留现有接触 + 词缀，并新增招牌：

- **震地践踏**：玩家在 120px 内时，0.7 秒预警，以自身为圆心 R110；1.0× 攻击物理，击退 80；冷却 6 秒。
- 施放时静止；硬直/冻结规则沿用现有精英。
- 词缀：分裂 / 召唤 / 冰霜新星（现有）。

### 5.4 飞行眼魔（远程精英）

**定位**：漂浮远程，靠射线和延迟区域逼走位，近身时闪烁脱离。

**行为**

- 保持 160–240px；玩家靠近 <90px 时优先闪烁。
- **凝视射线**：0.8 秒直线预警（宽 24、长 280，锁定施放瞬间方向），1.0× 攻击雷电，减速 30% 2 秒；冷却 5 秒。
- **重力塌缩**：0.9 秒圆形预警 R90，落在玩家施放瞬间位置；结算 0.8× 攻击雷电并减速 30% 2 秒；冷却 7 秒。
- **闪烁脱离**：玩家 <90px 时，0.3 秒淡出，向远离玩家方向闪现 140px（世界边界夹取）；冷却 4 秒；不造成伤害。
- 无直线弹丸；射线和落点都是可读预警。
- 词缀：沿用分裂 / 召唤 / 冰霜新星；分裂子体为同物种非精英。

**与射击区别**：射手是持续风筝 + 弹丸；眼魔是固定射线、延迟区域、短距瞬移，近战不能一直贴脸。

### 5.5 战鼓祭司（支援精英）

**定位**：强化周围敌人、用音爆环逼迫走位；不靠直接贴脸。

**行为**

- 保持 120–160px；玩家 <100px 后退。
- **强化光环**：140px 内友军 +20% 移速、+20% 伤害；同类不叠加。
- **音爆环**：0.7 秒预警，以自身为圆心扩散至 R150；0.6× 攻击物理；命中友军时给其 +20% 移速 3 秒；冷却 6 秒。
- 不主动召唤；召唤交给词缀（召唤蝙蝠），避免召唤叠加失控。
- 词缀：沿用现有三种；分裂子体为同物种非精英。

**与普通战鼓手区别**：普通鼓手只有光环；精英鼓手多了范围音爆与更强的光环，是优先击杀目标。

## 8. 实现交接

### 8.1 行为分派重构

`EnemySystem.updateEnemies` 目前已经是多个 `if/else` 分支；继续加 5 种行为会不可维护。建议：

- 在 `EnemyConfig` 或独立映射中增加 `behavior`：
  `chase | shooter | bomber | drummer | spinner | burrower | charger | lobber | bulwark | tether | eyeElite | drummerElite`。
- `updateEnemies` 只做通用阶段（计时、击退、状态、接触）并调用行为处理函数；新行为放 `src/game/core/behaviors/` 或 `EnemyBehaviors.ts`。
- 现有行为迁移时保持同样的随机调用顺序与移动结果，避免 parity 基线错位；如不能保证，分批迁移，先只给新类型走行为表。

### 8.2 精英物种与槽位

- 新增 `ELITE_SPECIES`（或扩展 `ETYPES` + `eliteOnly`）配置；包含基础数值、美术键、解锁波、槽位顺序。
- `WaveSystem.updateWave` 的精英分支按槽位选择物种，不再写死 `spawnEnemy("brute", true)`。
- `spawnEnemy(species, true)` 继续走通用精英倍率；词缀逻辑复用现有 `ELITE_AFFIXES`。分裂词缀按物种的 `baseType` 生成非精英子体。
- `killEnemy`：所有精英 `runEliteKills++`；Boss 才 `runBossKills++`（当前 bug：所有精英蛮牛都计入 bossKills）。
- 图鉴：新增 `e:shooter_elite`、`e:drummer_elite`；基础数值/护甲/抗性从对应配置读取。

### 8.3 方向护盾（晶甲虫）

- 新增可选字段：`guard?: { angle: number; arc: number; mul: number; downT?: number }`。
- 玩家攻击命中时按攻击来源方向判断是否在正面 120°；在正面则乘 `mul=0.4`；真实伤害忽略；DoT 不判定方向。
- 突进结束后 `downT=0.8`，期间护盾不生效；绘制正面护盾弧，关闭时变暗。
- 角度/来源的取法：玩家普攻与弹丸用玩家位置，AoE 用技能中心；实现时统一传入 `origin`，不要在每个攻击点写一套逻辑。

### 8.4 持续光束（缚电水母）

- 状态：`tether?: { angle: number; t: number; tickT: number }`。
- 预警阶段画细长直线；通道阶段每 0.3 秒对玩家做“点到线段距离”判定，命中调用 `damagePlayer`，类型雷电、`cause:"projectile"` 或新增合适 cause。
- 光束锁定方向，不追踪；水母通道期间静止，可被打断（受击/控制仍会停止，具体沿用敌人状态机）。
- 不新增敌方弹丸元素字段；全部用线段判定。

### 8.5 地面危险区（熔岩投手 / Boss 共用）

- 建议把 Boss 设计里的 `bossHazards` 泛化为通用 `hazards`：
  `{ kind: "fire" | "frost" | "lightning"; x; y; r; t; tickT; dmg; slowF?; hostile: true }`。
- 熔岩投手和 Boss 都写入同一个池；绘制按 kind 区分，结算统一走 `damagePlayer`。
- 不要复用玩家的 `burnZones`（那是玩家打敌人的）；不要为投手再复制第三套地面数组。
- 上限：火/冰地面同时最多 4 片；超限替换最旧或不再生成，避免无限堆叠。

### 8.6 精英攻击实现

- **震地践踏**：复用圆环预警 + `damagePlayer` + 击退；不需要新弹丸。
- **凝视射线 / 重力塌缩**：射线用线段判定；塌缩用延迟圆判定；都可复用现有地面/直线预警绘制。
- **闪烁脱离**：修改敌人坐标 + 淡出/淡入表现；不穿世界边界；不消耗额外随机。
- **音爆环**：用扩散圆环 + 距离判定；光环沿用 `drummerAura` 的“就近不叠加”逻辑，数值单独配置。
- 所有新攻击的伤害走 `damagePlayer`，类型/形式明确；不要绕过统一管线。

## 11. 开放问题

1. 精英物种数量：默认 3 种；若首版范围过大，可先做蛮牛 + 眼魔，鼓手精英延后。
2. 精英词缀是否允许重复：默认允许，但同一波优先不重复。
3. 晶甲虫护盾：默认正面 120°、60% 减伤、突进后关闭 0.8 秒；真实伤害穿透。
4. 缚电水母光束：默认锁定方向、不追踪；若太难躲可改为缓慢跟随。
5. 新怪是否新增主题：默认加入现有伏击/混合/狂潮，不新增主题。
6. 小怪美术：默认先程序化占位，外部 PNG 就绪后覆盖；不阻塞机制实现。
