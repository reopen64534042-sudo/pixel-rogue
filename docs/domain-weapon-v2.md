## 1. 攻击循环

**普通展开 → 普通展开 → 普通展开 → 强化展开（普通领域 + 额外黑洞） → 重复。**

- 每次自动瞄准范围内最近的存活敌人，保留短提前量。单次部署0.15秒，基础施放周期由0.9秒改为0.7秒；实际间隔为max(0.15,0.7/(施法速度×0.55))，周期包括部署时间。
- 每个普通领域落地打出独立0.6DWM首击，随后按自身位置/寿命持续跳伤、连斩与信息灌注。基础存在2秒；视界扩张+0.5秒、视界共振条件满足时再+0.5秒，最长3秒。
- 每次成功落地推进1个刻印；第四次在该落点立即追加黑洞，刻印归零。无目标不启动新施放；已经启动的部署照常落地。击杀数、多目标命中、信息回响、共鸣、余烬均不额外推进刻印或经验。
- 取消三领域数量门槛、重心合成、0.35秒搬移过程和2.5秒坍缩锁。旧场不会为黑洞提前结束，场数也不按三片截断；每片自然到期。
- 黑洞不暂停后续施放，每次强化产生的黑洞都走完自己的寿命，允许短暂共存；不替换、刷新或吞掉上一份奖励。领域/黑洞数量由最短部署间隔、强化频率与最长寿命自然限制。
- 三枚封印牌代表前三次刻印；第四次局部向黑洞汇入。旧收拢人物姿态复用于强化展开的0.35秒表现窗口，不延迟命中、不阻断施法。

## 2. 普通领域与空间连斩

| 分量 | 基础攻击力系数 | 节拍与规则 |
|---|---|---|
| 展开首击 | 0.6DWM | 每片落地一次，可暴击，不吸血/派生命中特效 |
| 持续跳伤 | 0.3DWM | 每0.25秒；落地首击独立，不同时补一跳 |
| 无量信息侵蚀 | 额外0.08DWM/跳 | Lv.3起并入领域跳伤 |
| 空间连斩 | 每刀0.14DWM | Lv.2起，每0.1秒全域结算，按目标去重 |
| 强化共鸣斩 | 0.6DWM | 持引力汇流时，每第四次展开覆盖所有现存领域，每目标仅取最强一份，可暴击 |

- 持续跳伤最多取两片领域：最强100%，第二份60%；第二份所属快照有引力汇流时为80%。所有普通领域的连斩共享节拍，同一目标只取最强一刀。
- 首击按每次施放独立结算；黑洞有各自的跳伤/连斩节拍。伤害系数和派生倍率在combatBalance/DamageMath统一定义。
- 每个实际命中的怪物身上播放0.09秒紫白短斜斩；伤害立即结算，连斩数字每0.3秒合并。免疫/被阻止的命中不生成假刀痕。
- 无量停滞期间暂停自主移动/攻击和领域系统牵引，原领域继续在原位置伤害该目标；过载结束再吸入。没有必须先拖到另一个合成点的条件。

## 3. 无量与Boss信息解析

### 普通/精英目标

- 最强一份来源以约0.2秒/M灌满信息，申请0.9秒×M连续过载；单次先夹紧1.2秒，再精英半效和100%/50%/25%递减。
- 恢复后0.8秒再灌注间隔；第三次成功后阻止新控制，直到该次结束再留2秒免疫。失败申请不延长窗口。多片领域和多个黑洞不能叠加灌注速度或刷新为无限硬控。
- 深空领域、信息汇入、静止轮廓与认知锁读取实际状态；恢复即清除停滞标记。

### Boss

- 不申请眩晕、不修改自主移动/出招。约0.6秒/M灌满后进入信息解析，使该Boss承受的领域系攻击力伤害×1.15；生命压缩不吃这份增幅。
- 信息解析持续0.8秒，持续覆盖时下一次灌满刷新；离开来源后最多0.8秒消退。Boss无敌/转阶段期间停止灌注并清除解析，伤害仍受正式Boss管线控制。
- Boss使用紫色解析环与“解析”标记，没有普通怪的停滞锁。
- 静滞增幅也识别解析中的Boss，额外×1.2；与解析倍率各应用一次，不将Boss伪装为被眩晕。

## 4. 黑洞奖励

- 出现在第四次普通领域的落点，形成时结算2DWM引力主爆发（可暴击）、0.4DWM真伤（不暴击）和min(4%伤前HP,1DW)×M生命压缩。主爆发/真伤按已有B等倍率结算，生命压缩独立，不吃B/F、暴击、信息解析或通用攻击增伤。
- 基础存在1秒，视界扩张+0.6秒、坍缩理论+0.4秒、回响奇点最多+0.4秒，最长2.4秒。
- 每0.2秒基础跳伤0.12DWM；解锁连斩后每0.1秒(7/60)DWM。终末系数1.2DWM，余烬为来源基础跳伤的40%，延续原派生限制。
- 24px/s巡游，引力增幅后30px/s；每0.2秒在240px内重新选择目标。优先可攻击的Boss，否则按附近敌群密度与换群距离阈值选择。伤害和牵引跟随真实位置，不重复形成爆发或刷新寿命。
- 牵引每目标每步只采用最强一份；过载目标保持原位。Boss硬控免疫；绝对引力只在其追逐阶段允许30%黑洞牵引。
- 多个黑洞独立存续，终末各一次；余烬仍最多一份，新结束黑洞的余烬替换旧余烬。

## 5. 升级与天赋改接

Lv.2固定连斩，Lv.3固定无量，其余九项Lv.4–12随机顺序，满级全拿。人物与武器的最新成长保留：人物每级生命+0.5/基础伤害+0.4/领域值+0.5/施法速度+0.2%，另有2属性点；W=1+0.12×(武器Lv−1)，领域值强化+6/+9/+12/+18、总上限200。

| 项目 | V2职责 |
|---|---|
| 视界扩张 | 普通领域+0.5秒（多5轮连斩），黑洞+0.6秒 |
| 引力汇流 | 强化展开触发现存领域共鸣斩；重叠第二份跳伤60%→80% |
| 信息回响（替换禁锢） | 无量过载结束或Boss灌满解析时，对该目标追加0.8DWM引力伤害；无暴击，每目标间隔至少1.2秒，无额外控制/刻印/经验，不要求核心链 |
| 引力核心 | 记录本轮普通领域首击/跳伤/连斩实际伤害命中的不同目标；第四次形成按8%+每目标2%、最多30%增强黑洞攻击分量，单个Boss也计数 |
| 坍缩理论 | 黑洞持续+0.4秒、牵引+25%，无禁锢后置门槛 |
| 引力护盾 | 普通展开首击实际造成HP损失后触发；盾量(5%+实际受伤目标数×1%)×M，最多15%最大生命，3秒持续/2.5秒冷却，刷新不累加 |
| 逃逸速度 | 每第四次强化展开触发1.5秒加速 |
| 质量回收 | 普通首击/跳伤/连斩击杀返还施法冷却，每次落地后最多0.3秒；不缩部署、不刷刻印 |
| 重力碾压 | 普通领域/连斩/黑洞的引力伤害均无视剩余护甲30%，真伤不重复获益 |
| 绝对引力 | 精英牵引全效；全部领域系攻击力分量对Boss+10%，保留Boss出招保护 |
| 静滞增幅 | 普通过载或Boss解析中，攻击力分量+20%，不放大生命压缩 |

裂界增幅、回响奇点、视界共振、质量聚焦、奇点步、质量虹吸沿用已实现的数值职责；描述同步到新循环。信息回响复用被替换的禁锢获取声与原binding-lock技能声，未重新生成WAV。

## 6. 快照、清理与表现

- 成功落地先获得限速后的武器经验，再快照本片领域；黑洞形成另快照当次等级/属性与本轮命中数量。已存在实体不回写新成长，信息回响保留对应过载来源快照。
- 额外首击、共鸣、信息回响与多黑洞各走统一伤害管线；不重复乘W/M，不递归触发黑洞、刻印、经验或额外命中派生。
- 暂停冻结模拟时钟；收波/重开清除刻印、实体、命中集合、信息回响队列、解析/控制状态与声音。表现尾迹可按既有接口保留。
- 地面绘制可跳过被更新同类领域完全覆盖的旧纹样，实际领域/范围/寿命不受影响；角色、地面危险预警与已认可连斩/无量层次保持。
- HUD和三枚刻印显示四次强化进度，C面板显示活动领域/黑洞数、首击、Boss解析、回响与下一武器等级倍率。
