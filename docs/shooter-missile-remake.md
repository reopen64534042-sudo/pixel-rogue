# 射手导弹武器重制方案

状态：2026-10-31 启动。已确认初始使用重型制导爆破，蜂群齐射与能量连锁由成长解锁；第二稿厚重军事化造型已获认可，用户随后要求按第二稿制作完整动画。素材阶段已完成 12 组、96 帧槽位、透明图集与完整周期离线预览，详见 [导弹动画素材包](missile-vfx-assets.md)。武器规则尚未接入；下面的具体卡名、数值与成长表均为首轮提案，尚未实现或配平。

开发分支为 `codex/shooter-missile-remake`，独立工作树为 `E:/AllProjects/pixel-rogue-missile-remake`，基于 `origin/main` 的 `c3dee30`（v140）。旧 `feat/shooter-weapons` 分支的 `341403e` 只作为历史参照，不直接移植其 6 级成长、4 个升级与 3 张专属卡。

## 已确认的方向

- 初始武器是重型制导导弹，自动索敌与发射，保留射手的移动、冲刺与距离决策。
- 蜂群多弹齐射和科幻能量连锁都可以通过武器升级或专属天赋解锁。
- 从弹体、完整动画、爆炸特效到成长与天赋全部重制。
- 第一张骨白装甲、蓝色大尾翼的候选图已被第二稿替代；第二稿厚重灰色装甲、短尾翼与短尾焰获用户认可，用于本批动画素材。

## 基础战斗循环

一枚主导弹经过侧向出舱、点火加速、弧线制导、命中爆破和消散。发射节奏留出明显的装填空隙，玩家在这段时间移动聚怪、调整下一枚导弹的锁定目标；攻速提高装填效率，不把所有飞行动画等比加速。

基础形态就具有可靠的追踪和小范围爆破，不依赖抽到天赋才能清理怪群。目标死亡后从导弹当前位置重新索敌；短暂无目标时沿原方向飞行，寿命结束安全清理。出舱阶段不突然折返穿过玩家，进入制导阶段后才完整追踪。高速飞行使用线段扫掠判定，避免飞过小怪而漏判。

爆炸中心来自真实接触点。核心爆炸即时结算一次，后续烟尘与火星只作表现；延迟伤害、子弹与电弧必须各有明确的真实事件，不能按动画帧重复结算。基础爆炸走物理／远程管线；能量战斗部的指定伤害改走雷电／远程管线，不旁路护甲、抗性或高波动态减伤。

首轮调参范围建议：出舱约 0.10—0.14 秒、加速约 0.16—0.22 秒，爆炸半径约 24—28px。初始一轮发射的间隔约 1 秒；具体攻击倍率在 DamageMath 与 combatBalance 中集中配置，结合射手当前基础攻击和输出速率计算。以上不是已经确定的战斗数值。

## 三种形态与组合

| 形态 | 解锁位置 | 战斗用途 | 画面识别 |
|---|---|---|---|
| 重型制导 | 基础武器与猎杀天赋链 | 追踪高价值目标，利用装填间隙保持距离 | 厚重短弹体、短促橙白喷流、紧凑爆心与扩散尘环 |
| 蜂群齐射 | 蜂群天赋链 | 以附加微型弹分配火力，处理分散小怪 | 小尺寸弹体、独立弧线与短尾迹，清楚区分主弹和子弹 |
| 能量连锁 | 离子天赋链 | 爆破后连接不同目标，补足爆炸范围外的覆盖 | 保留军械外壳，局部青色充能；命中后出现短时电弧 |

三者允许组合。重导弹始终是基础；蜂群给它增加独立的小弹；离子战斗部改变指定主弹与命中后的联动。组合时不得把主弹和全部子弹都复制成完整的连锁发射器，触发权限必须由来源类型明确限制。

## 武器成长提案

建议沿用当前射手的 12 级成长结构，Lv.4—12 每级获得一个未持有的硬件升级，共 9 条。硬件负责弹体与发射性能，专属天赋负责产生新行为。升级的候选开放等级须保证每次成长至少有一条可获得升级。

| 硬件 | 提案效果 | 表现变化 |
|---|---|---|
| 扩容战斗部 | 增大主爆炸范围 | 更宽的尘环与破片包络，亮爆心保持短暂 |
| 远程火控 | 延长索敌射程 | 锁定指示随真实目标与实际射程更新 |
| 矢量喷口 | 提高制导转向能力 | 喷流沿真实转弯方向偏折 |
| 助推发动机 | 提高巡航速度 | 喷流短暂压紧，尾迹采样保持连续 |
| 快速出舱 | 缩短出舱阶段 | 保留明确的出舱／点火区别 |
| 自动装填机 | 缩短装填间隔 | 脚下装填提示按真实余时推进 |
| 复合装甲壳 | 提高主弹基础爆破威力 | 弹体增加可辨认的深色护套，不无限放大贴图 |
| 双联挂架 | 一轮依次发出两枚主弹，降低每枚伤害控制总量 | 两侧错时出舱，允许共同追踪；仍算一轮成长机会 |
| 重型增压弹 | 周期性把一轮主弹变为重型弹 | 弹体护套、尾焰与命中尘环有所区别；次数读取真实状态 |

武器经验按“这一轮主弹至少造成一次有效命中”发放，每轮最多一次。双联、多目标爆炸、蜂群、连锁、燃烧、回收弹与猎杀追击都不能倍增经验。教程内不累计成长；满级后停止抽取升级。经验阈值与成长倍率在玩法接线阶段单独确定。

## 专属天赋提案

建议 14 张、全部一次性获得；三条各 3 层的行为链，另有 5 张独立机制卡。前置必须持有才进入候选，卡名落地前检查全局唯一性。具体数量仍可随首轮玩法评审调整。

### 猎杀链

1. **猎杀信标**：主导弹命中锁定目标，为它留下短时信标。下一轮优先追踪仍在射程内的信标目标，对该目标获得额外收益。每个玩家只维护一个信标，让集中火力与改换目标形成取舍。
2. **弱点破译**：连续命中信标目标积累破译次数，下一次主弹对该目标附加受上限约束的真实伤害，随后消耗次数。只影响指定目标，不把整片范围爆炸转成真实伤害。
3. **终结指令**：主弹击杀信标目标后，发射一枚降低威力的追击导弹寻找下一目标。追击不再触发追击，不提供武器经验，受独立冷却限制。

猎杀链最终改变目标选择与击杀后的节奏；高层卡不能只把第一层的倍率再翻倍。

### 蜂群链

1. **蜂巢弹舱**：每隔若干轮主发射，额外放出两枚小型制导弹。主弹保留，小弹使用独立的低伤害、小半径配置。
2. **分导协同**：小弹优先分配给主弹预期爆炸范围外、尚未被其他小弹预约的目标；目标不足时允许集火。重新索敌沿用相同规则，不强行分散到射程外。
3. **蜂群回收**：合资格的基础小弹击杀获得有限弹舱充能，下一轮释放额外回收小弹。回收小弹不能再返还充能，切断自我复制循环。

蜂群的每枚小弹都必须实际飞行、独立命中。不能用一次范围伤害配多条装饰尾迹冒充多弹齐射。

### 离子链

1. **离子战斗部**：周期性主弹改为离子爆破，指定主弹伤害使用雷电属性；命中后向少量未被本次爆炸覆盖的附近敌人产生短电弧。
2. **电弧接力**：电弧端点可以再接力一次，衰减后继续寻找未命中的敌人；一轮共用访问集合和总目标上限，不能来回弹跳同一组目标。
3. **过载共振**：主弹离子爆破与电弧在目标上留下短时电荷，达到阈值后消耗电荷并产生一次小范围放电。放电不能继续制造电荷、接力或其他子弹。

雷电仅属于明确的离子来源；普通弹不能因为持有离子卡就把所有伤害无条件改成雷电。电弧表现的开始与端点必须来自实际结算事件，不向没有受到该次伤害的敌人画连接。

### 独立机制卡

| 天赋 | 玩家动作与收益 |
|---|---|
| 惯性装填 | 装填阶段冲刺，缩短当前剩余装填；每轮一次，不凭空补发整轮主弹 |
| 近炸保险 | 敌人进入近身范围时触发短距防御冲击，击退并留出重新拉开距离的窗口；有冷却，不给经验 |
| 弹幕掩护 | 主爆炸可以清除范围内少量敌方弹幕，有单次上限与触发间隔 |
| 余烬滞留 | 合资格物理主爆炸留下短时小范围燃烧，按统一伤害管线积分；同源重叠不无限堆叠 |
| 应急装甲 | 装填阶段获得有限减伤，鼓励利用明确的进攻与防守节奏 |

## 动画与特效规格

### 弹体

军事化方向使用较短较厚的装甲壳、钝锥头、分段接缝、短矩形尾翼、低饱和灰与深色金属。警示环只占小部分面积；导引头不做醒目的能量宝石。主弹、小弹与离子弹共用制造语言，靠轮廓尺寸、尾部结构与局部充能区别。

先制作视觉种子，再在游戏原尺寸与放大尺寸并排检查。最终主弹占位应相对当前 8×10px 玩家可读；源图的大尺寸观感不能代替缩小后的辨识度。固定共享画布、锚点、弹体比例与朝向，不能逐帧按内容包围盒重新缩放。

### 动作阶段

| 阶段 | 动作与层次 | 时间依据 |
|---|---|---|
| 出舱 | 短距离侧向抛出，弹体先出现；出舱烟气留在原发射点 | 真实出舱阶段余时 |
| 点火 | 喷口短白闪、紧凑火舌建立，随后加速；弹体不突然改变尺寸 | 真实点火与加速进度 |
| 制导 | 弹体沿真实速度转向，喷流随转向轻偏；尾迹保留历史位置 | 导弹模拟时间与实际轨迹 |
| 命中 | 接触点短爆闪，弹体消失，碎片沿合理方向散开 | 一次真实引爆事件 |
| 爆破 | 白热核心快速退出，橙色火团张开，薄尘环向外扩散 | 表现事件年龄，不再造成重复伤害 |
| 消散 | 暗橙碎火、稀疏余烬与半透明烟尘错时退出 | 固定短寿命，暂停时冻结 |

建议把最亮核心限制在约 60—90ms 内，总爆炸余波约 0.45—0.65 秒。烟尘尽快变薄、中心留空；精英、敌方预警、地面危险与玩家轮廓在爆炸后仍然可读。基础攻击不叠全屏白闪，不给每枚蜂群小弹增加独立镜头震动。

### 素材拆分

| 素材组 | 初步规格 | 播放方式 |
|---|---|---|
| 主弹体 | 32×16 画布，固定弹体锚点 | 金属外壳稳定，按真实速度旋转 |
| 小弹体 | 16×8 或 16×16 画布 | 独立可辨的微型轮廓 |
| 出舱烟气 | 32×32，6—8 帧 | 原发射点单次播放 |
| 点火喷流 | 32×16，8 帧 | 一次建立后转巡航循环 |
| 巡航尾焰 | 32×16，6—8 帧 | 无闪断循环；不拉伸金属弹体 |
| 爆闪与主火团 | 64×64，12—16 帧 | 固定爆心，按参考爆炸半径显示 |
| 尘环与余烟 | 64×64，10—12 帧 | 与主火团错时推进，后段降亮度 |
| 余烬 | 32×32，6—8 帧 | 少量、短时、明确退场 |
| 离子命中 | 64×64，8—12 帧 | 青白短爆心，保留基本尘环结构 |
| 电弧纹理 | 32×16，4—6 帧 | 按真实端点分段绘制，单次短闪 |

本表保留初步制作预算，当前实际交付为 12 组、每组 8 帧，具体画布、锚点与秒数见素材说明和 `missile.metadata.json`。动画基于认可的种子按完整序列生成；后处理使用统一采样网格与组内共享比例，保留透明通道、固定锚点和统一朝向。主导弹飞行时的平移与转弯由模拟提供，不烘焙成固定弧线贴图。

制作输出包括原始源图、完整提示词、来源记录、正式透明条带／图集、每帧时长与锚点元数据，以及原速、慢放和 1 倍游戏尺寸预览。静态视觉稿不记为正式动画完成。

## 接入边界

- `data/missile.ts`：武器节奏、经验表、硬件升级、运行态类型；与旧强化弹遗留 `Missile` 区分。
- `data/combatBalance.ts` 与 `core/DamageMath.ts`：所有新增伤害倍率与公式。
- `core/MissileSystem.ts`：装填、出舱、制导、扫掠命中、引爆、经验与各类派生来源。
- `data/talents/missile.ts`：专属卡面、依赖与武器门控；属性与临时状态不混放。
- `rendering/vfx/missile/`：只读快照、动画采样、Phaser 对象池和离线预览后端。
- `GameCore`：武器选择、每局运行态、重开保留武器与完整重置。
- 开始界面、教程、C 面板、DEV 面板、伤害报告、图鉴：展示真实武器状态并支持导弹入口。

当前主线只有 `charged | laser` 两种射手主武器；`SpecialSystem` 的旧导弹属于强化弹历史预留，使用简单追踪与爆炸。新系统不能往这套旧对象里塞入所有新状态，也不能让新旧更新器同时推进同一枚导弹。只复用统一战斗管线、公共几何或加载接口等确有价值的基础设施。

### 派生来源权限

主弹、蜂群基础小弹、回收小弹、猎杀追击、电弧、共振、燃烧分别标识来源。一轮共用经验记账；允许暴击、命中特效、吸血、击杀联动的来源必须明确声明，禁止靠调用层级隐式继承。

建议主爆炸同一枚弹共用一次暴击结果，主目标可触发一次命中特效；范围内其他目标不重复刷连锁。吸血按实际 HP 损失、范围攻击效率和共享时间预算限制；派生伤害默认不给武器经验、不触发命中特效、不递归产生同类派生。具体预算与 CombatSystem 的现有能力一同落实。

### 生命周期与性能

所有可变玩法状态归每个 GameCore；渲染不消费战斗 RNG。动画读取模拟时间与真实事件，暂停、属性面板冻结时同步停止。死亡、重开、回到开始界面、教程、DEV 跳波与清天赋必须处理飞行物、信标、电荷、燃烧与表现事件。

表现使用对象池、视野裁切与分层预算；高压时优先减少低亮烟尘和装饰火星，保留弹体、真实锁定、爆心与敌方预警。不能通过丢弃伤害事件或删除仍有效的主弹来换取表面流畅。离线预览展示单发、转向、目标死亡后重索敌、双联、蜂群、离子与三者组合；预览不代替自然战斗验收。

## 实施顺序与交付

1. 定稿重型军事化种子，检查游戏尺寸；完成出舱、点火、巡航、爆破与消散的一整套素材及离线周期预览。
2. 接通基础重型导弹、武器选择、成长、教程、重置与 C 面板，让不持有专属天赋的基础循环成立。
3. 实装猎杀、蜂群、离子三条链与支持卡；明确组合规则、派生权限与经验上限。
4. 同步图鉴、伤害报告、DEV、文档；功能交付时更新双端 changelog，版本号按当时最新主线递增。
5. 按项目当前交付线运行 typecheck 与 build，检查差异；不主动新增测试、不运行 Vitest／Playwright、不补 parity 基线。自然强度、弹道手感、爆炸遮挡与帧率留待用户授权的试玩批次。
