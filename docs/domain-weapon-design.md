# 法师独立武器 · 坍缩领域（Domain Weapon）设计

> 状态：**设计定稿，尚未接入运行时代码**。
> 代码基线：`upstream/main` v156（`4fdeb49`）。
> 分支：`feat/domain-weapon`。
> 读者：Codex（实现）、美术、平衡与试玩。
> 相关文档：`docs/shooter-laser.md`（武器成长/专属池结构）、`docs/combat-numerics-agent-guide.md`（伤害管线）、`docs/boss-three-headed-beast.md`（Boss 控制抗性口径）。

## 1. 一句话

法师开局二选一：现有「法阵」或新武器「坍缩领域」。坍缩领域不依赖元素、充能、站定、星陨、双修或元素残域，自己构成一套完整武器：放领域 → 牵引/减速/持续伤害 → 第三个领域坍缩为黑洞 → 武器升级与专属天赋继续强化黑洞和领域形态。

## 2. 已确认决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | 挂载方式 | **独立武器**：法师开局在「法阵 / 坍缩领域」中二选一 |
| 2 | 元素依赖 | **完全独立**：不要求元素卡，也不使用元素状态/反应 |
| 3 | 三张 L3 | **不互斥，可以都选**；用每张的代价与控制递减兜底 |
| 4 | 传统法师系统 | **不接入**：不使用元素、充能条、站定、星陨、双修/三修、元素残域、法师传统节律/范围/循环/脱离卡 |

## 3. 范围与非目标

### 3.1 本版包含

- 法师第二把武器 `domain`，开局选择与重开保留。
- 独立的施法计时、3 领域资源、坍缩与黑洞状态。
- 引力伤害类型、武器经验/等级/升级、15 张专属天赋。
- 3 格领域指示、黑洞倒计时、武器经验条、C 面板、图鉴。
- 收波、死亡、重开、暂停、属性面板冻结的完整清理。
- Boss/精英的控制抗性与牵引抗性口径。

### 3.2 本版不做

- 不改动现有「法阵」的任何数值、卡池或行为。
- 不做手动瞄准/放置；仍为自动索敌自动施放。
- 不做元素状态、元素反应、充能条、站定判定。
- 不做新 Boss、新敌人、新地图或独立技能栏。
- 不做多黑洞叠加；场上最多 1 个黑洞。
- 不新增 Vitest/Playwright 基线；验证按项目当前交付线执行。

## 4. 与现有法师的隔离

### 4.1 武器枚举

```ts
type MageWeapon = "arcane" | "domain";
```

- `arcane`：现有法阵体系，默认值，行为不变。
- `domain`：坍缩领域，进入 `DomainSystem` 分支。

### 4.2 运行时隔离

- `MageSystem` 在 `mageWeapon === "domain"` 时**直接早退**，不推进施法状态机、充能条、站定判定、星陨路线或元素残域。
- `DomainSystem` 拥有自己的施法计时、领域数组、黑洞、坍缩锁和武器成长状态。
- 领域武器不读取 `mageCharge`、`mageDomains`、`mageWindup`、`mageIsSteady`、`mageDamageType`。
- 领域武器的伤害类型为独立的 `gravity`，不进入元素抗性与元素状态逻辑。

### 4.3 卡池隔离

- 选 `domain`：只提供 `prof === "mage" && mageWeapon === "domain"` 的专属卡；所有传统法师卡过滤。旧表通用卡当前整体 `hidden`，实际不参与抽取；未来若恢复通用卡，再按白名单接入。
- 选 `arcane`：只提供现有传统法师卡；领域专属卡过滤。
- 其他职业卡继续由现有 `prof` 过滤，不受影响。

### 4.4 教程隔离

- 传统法师教程只属于 `arcane`。
- 选 `domain` 时不进入传统法师教程，也不把「法师教程已看」标记写成已看；首版直接开局，后续可补一个「放三个领域触发坍缩」的独立教程。

## 5. 核心循环

### 5.1 施放

- 每 `0.9s` 自动施放一次；施法速度仍吃通用 `fireRate`，实际间隔 = `0.9 / (player.fireRate × 0.55)`。
- 0.25 秒部署动画**不可打断**；领域在动画结束时落下。领域武器没有「被打断则这一发作废」的时间门控。
- 自动选择射程内实际覆盖人数最多的位置；落点按敌人真实速度做 `0.25s` 提前量。
- 落点优先避开玩家 48px 内，避免把自己的领域放在脚下把敌人拉到脸上。
- 有新领域时优先与已有领域保持 40px 以上距离；找不到合适点时，围绕最密集处按固定角度铺开，保证三个领域能形成可见的三角/分散布局，而不是叠在同一个点。
- 场上最多 3 个普通领域；第 4 个施放时替换最旧的一个（最旧领域直接消失，不触发坍缩）。
- 没有射程内目标时不施放，不获得武器经验；已存在的领域继续走完寿命。

### 5.2 普通领域

| 参数 | 首版值 | 说明 |
|---|---:|---|
| 半径 | 50 | 吃 `player.area`；领域专属卡可再乘 |
| 持续 | 3.0s | 到期自然消失 |
| 伤害节拍 | 0.25s | 每跳 `0.2 × 玩家伤害` |
| 每秒伤害 | 0.8 × 玩家伤害 | `0.2 / 0.25` |
| 减速 | 30% | 只取最强领域，不叠加 |
| 向心牵引 | 40px/s | 普通敌人；精英 50%，Boss 0 |

- 领域伤害走纯 DoT 路径（`applyDotDamage` 口径）：保留浮点、不暴击、不逐跳飘字。
- 同一目标最多同时受 **2 个领域**跳伤：第一个 100%，第二个 60%；第三个领域不额外跳伤，只参与坍缩。
- 牵引与减速只取场上最强的一份，不按领域数量叠加。
- 领域对普通敌人、精英、Boss 都造成伤害；控制按第 8.4 节抗性口径处理。

### 5.3 三个领域与坍缩

- 三个普通领域**默认同源**：不需要元素，也不判断元素类型。
- 第 3 个领域落下后，若坍缩锁已结束：
  1. 三个领域进入 0.35 秒「牵引」阶段，停止伤害跳数；
  2. 三个领域向三点重心收缩，牵引强度提升到 1.6×；
  3. 在重心生成黑洞，三个普通领域消耗。
- 若坍缩锁尚未结束：三个领域继续正常跳伤和牵引，锁结束后立刻进入 0.35 秒牵引阶段。HUD 显示「坍缩锁定 x.xs」。
- 坍缩锁：每次**坍缩开始**后 `2.5s` 内不能再次坍缩（第 3 个领域触发坍缩时开始计时）。基础 0.9s × 3 = 2.7s 一轮时锁不生效；高攻速下用来限制黑洞常驻。
- 场上最多 1 个黑洞；新黑洞形成时若旧黑洞仍在，旧黑洞立刻结束（不结算额外伤害）。

### 5.4 黑洞

| 参数 | 首版值 | 说明 |
|---|---:|---|
| 半径 | 55 | 吃 `player.area`；升级可再乘 |
| 持续 | 1.0s | 「初始持续 1 秒」 |
| 形成爆发 | 1.2 × 玩家伤害 | 走命中管线，每个敌人一次 |
| 持续跳伤 | 每 0.2s `0.35 × 玩家伤害` | 5 跳，走 DoT 路径 |
| 合计伤害 | 2.95 × 玩家伤害 | `1.2 + 0.35 × 5` |
| 牵引 | 普通领域的 2.2× | 普通敌人；精英 50%，Boss 0 |
| 减速 | 50% | Boss 沿用现有减速效果倍率 |

- 形成爆发走 `hurtEnemy`，每个敌人只弹一次伤害数字；持续跳伤不逐跳飘字。
- 黑洞伤害类型为 `gravity`，吃护甲；专属卡「重力碾压」可无视 30% 护甲。
- 黑洞是控制爆发，不是永久控制；Boss 免疫牵引与眩晕/定身，精英控制时长减半。

### 5.5 边界情况

- 领域在敌人全部死亡后仍存在并走完寿命；有新目标时会正常索敌施放。
- 第 3 个领域落下时没有敌人也能坍缩；黑洞正常生成但无伤害目标。
- 领域自然到期不触发坍缩；剩余领域继续存在，直到全部到期。
- 第 4 个领域替换最旧领域时，不返还冷却、不触发「质量回收」；「质量回收」只认自然到期。
- 收波、死亡、重开、返回开始、DEV 跳波、清天赋：清空领域、黑洞、坍缩锁、控制抗性计时。
- 暂停与属性面板冻结整个模拟；领域/黑洞计时跟随固定步长暂停，恢复后继续。

## 6. 伤害属性与管线

### 6.1 引力伤害

在 `src/game/data/damageTypes.ts` 增加：

```ts
gravity: { mitigation: "armor", label: "引力" }
```

- 与物理一样吃护甲，但不吃火焰/冰霜/雷电抗性。
- 不触发元素状态、元素反应、闪电链、冻结或麻痹。
- 不新增敌人抗性字段；未来要给敌人加「引力抗性」时再扩展。

### 6.2 管线约定

- 普通领域跳伤：`applyDotDamage`，保留浮点、不暴击、无飘字。
- 黑洞形成爆发：`hurtEnemy`，走完整命中管线；可暴击、吃增伤、吃护甲/破甲，每个敌人一次飘字。
- 黑洞持续跳伤：纯 DoT 路径，无飘字。
- 多重斩击：按「每个敌人每个斩击波次最多一次」聚合后走命中管线，每个敌人每波只弹一次数字，避免满屏数字。
- 所有伤害计入「坍缩领域」分项，不混入法师元素伤害。

## 7. 武器成长

### 7.1 经验与等级

- 每次成功施放领域 +1 武器经验；每 0.5 秒最多获得 1 点，坍缩本身不给经验。
- 教程内不获得武器经验。
- 12 级满级；升到下一级所需经验：

```text
4 / 7 / 11 / 16 / 22 / 29 / 37 / 46 / 56 / 67 / 79 / 满
```

- Lv.4–12 每级从「达到开放等级、尚未获得」的升级中随机取得一条；共 9 条，满级可以全部获得。
- 结构沿用激光/导弹的武器成长，不与天赋卡池混用。

### 7.2 升级表

| 升级 | 最早等级 | 效果 |
|---|---|---|
| 奇点半径 | 4 | 黑洞半径 +20% |
| 引力增幅 | 4 | 黑洞牵引 +25% |
| 视界扩张 | 4 | 黑洞持续 1.0 → 1.4 秒 |
| 质量投射 | 5 | 黑洞伤害 +20% |
| 领域延展 | 5 | 领域半径 +15%，减速 +5 个百分点 |
| 事件视界 | 6 | 黑洞内敌人无法离开；黑洞半径 +10% |
| 奇点余烬 | 7 | 黑洞结束后留下 1.2 秒余烬领域（40% 跳伤与牵引） |
| 双星系统 | 9 | 2 个领域即可坍缩；黑洞爆发/跳伤 ×70%，持续固定 0.8 秒，不吃视界扩张与坍缩理论 |
| 终末奇点 | 11 | 黑洞结束时再造成一次 0.8× 玩家伤害的坍缩爆发 |

- 「双星系统」必须保留限制，否则高攻速下 2 领域循环会接近黑洞常驻。
- 9 条升级对应 Lv.4–12 共 9 次抽取；满级全拿，不设随机漏项。

## 8. 专属天赋

全部 `prof: "mage"`、`mageWeapon: "domain"`、`max: 1`、`t: 0`、`f: () => {}`；机制通过 `upCounts` 在消费点读取。

### 8.1 核心两层

| 天赋 | 前置 | 作用 |
|---|---|---|
| 引力核心 | 无 | 坍缩时，三个领域覆盖范围内每有 1 个不同敌人，黑洞伤害 +1%，上限 +30% |
| 坍缩理论 | 引力核心 | 黑洞持续 +0.4 秒，牵引 +25%；解锁三张 L3；与视界扩张叠加 |

### 8.2 L3：三张不互斥

三张都要求「坍缩理论」，可以全部获得；效果叠加，各自带代价。控制递减见 8.4。

| 天赋 | 效果 | 代价/边界 |
|---|---|---|
| 无量空处 | 领域不再牵引；敌人进入领域眩晕 0.6 秒，之后每 1.2 秒眩晕 0.4 秒；黑洞持续眩晕，但牵引 ×0.6 | 领域伤害 ×0.85，黑洞伤害 ×0.9；Boss 免疫眩晕，精英时长 ×0.5 |
| 多重斩击 | 每个领域每 0.9 秒对最多 3 个敌人各造成 0.7×D 斩击，同一敌人同一波次最多 1 刀；黑洞每 0.3 秒对范围内全体造成 0.35×D | 领域跳伤 ×0.9；斩击按敌人聚合飘字，每波只弹一次 |
| 禁锢 | 敌人进入领域定身 1.0 秒（可攻击、不可移动），同一敌人 3 秒内最多触发一次；黑洞形成时定身 1.0 秒；牵引 ×1.2 | 领域伤害 ×0.9；Boss 免疫定身，精英时长 ×0.5 |

- 三张全选时，普通敌人会同时承受眩晕脉冲、定身和斩击；这是三次天赋投资的完整形态，Boss 仍只吃伤害与减速。
- 若实机出现普通波次完全无交互，优先调 8.4 的控制递减，而不是直接删除其中一张。

### 8.3 可选专属卡

| 天赋 | 作用 |
|---|---|
| 引力护盾 | 站在自己领域内受伤 −8%；坍缩时按牵引敌人数获得护盾（每个 1% 最大生命，上限 15%） |
| 逃逸速度 | 坍缩后 1.5 秒移速 +20% |
| 质量回收 | 领域自然到期未坍缩时，返还 0.3 秒施法冷却并获得 2% 最大生命护盾 |
| 重力碾压 | 黑洞伤害无视 30% 护甲 |
| 绝对引力 | Boss 牵引抗性 100% → 70%，精英 50% → 0；对 Boss 黑洞伤害 +10% |
| 回响奇点 | 黑洞每击杀 1 个敌人，持续 +0.08 秒，最多 +0.4 秒 |
| 视界共振 | 黑洞存在期间新放的领域牵引 +30%，持续时间 +0.5 秒 |
| 质量聚焦 | 领域半径 −15%，黑洞伤害 +25% |
| 奇点步 | 冲刺时在原地留下 0.6 秒小型引力涡流，牵引附近敌人；每 4 秒一次 |
| 质量虹吸 | 每个被拉入黑洞的敌人回复 0.3% 最大生命，每次坍缩最多 5% |

### 8.4 控制递减

领域眩晕/定身使用独立的递减，不改变现有冻结、麻痹、战士眩晕：

- 每个敌人维护 `domainCcResist`（0/1/2）与 3 秒重置计时。
- 3 秒内第一次被领域眩晕/定身：完整时长，抗性 +1。
- 3 秒内第二次：时长 ×0.5，抗性 +1。
- 3 秒内第三次：免疫 2 秒。
- 3 秒内没有再次被领域控制：抗性清零。
- Boss 直接免疫眩晕/定身；精英先按时长 ×0.5，再走递减。

## 9. 卡池、UI 与图鉴

- 开始游戏 → 法师 → 选择「法阵 / 坍缩领域」。

- C 面板武器区显示：领域半径、持续、每跳伤害、牵引、减速；黑洞半径、持续、爆发/跳伤、牵引；武器等级、经验、已获得升级。
- 图鉴增加「坍缩领域」武器条目、9 条升级、15 张天赋、黑洞条目；槽位标注「坍缩领域 · 核心 / L3 / 增幅 / 生存」。

- 等级选择、卡池过滤、重开、跳波与清理接入新状态。

## 10. 表现与性能

### 10.1 视觉

- 普通领域：低饱和紫灰双环 + 向内细弧，中心不填充；两个领域之间出现细连线；第三个落下时三环收缩到重心。
- 黑洞：深色核心 + 细吸积环 + 向内粒子；不闪白、不满屏亮色，与元素残域的橙色明确区分。
- 坍缩牵引阶段只做收缩和连线，不做全屏闪光。
- 领域/黑洞的判定半径与绘制半径一致，外发光不扩大判定。

### 10.2 伤害文字

- 普通领域跳伤：0 飘字。
- 黑洞形成爆发：每个敌人 1 条。
- 黑洞持续跳伤：0 飘字。
- 多重斩击：每个敌人每个斩击波次最多 1 条，聚合后显示。
- 避免出现元素残域曾经「每帧 1 点、满屏 1」的问题。

### 10.3 性能

- 场上最多 3 个普通领域 + 1 个黑洞。
- 领域每 0.25 秒、黑洞每 0.2 秒结算；每个领域对敌人做一次半径判断。
- 不逐帧创建对象；粒子、环、文字复用现有池。
- 暂停/属性面板冻结时所有计时停止；收波/死亡/重开立即清空。
- 目标上限与伤害聚合在系统层完成，不依赖渲染层裁剪。

## 11. 平衡基线

以玩家伤害 D 为基准，首版算术：

| 形态 | 单目标 DPS | 说明 |
|---|---:|---|
| 法阵（现有） | 1.64×D | 0.9× / 0.55s |
| 星陨 L1 | 2.0×D | 4.0× / 2.0s |
| 多重陨星 L2 | 3.2×D | 2 × 4.0 × 0.8 / 2.0s |
| 坍缩领域 | ≈1.79×D | 3 领域递减 + 每 2.7s 一次黑洞 |

坍缩领域单目标：

```text
领域：0.8×1.8 + 0.48×0.9 = 1.872×
黑洞：1.2 + 0.35×5 = 2.95×
合计：4.822× / 2.7s ≈ 1.79×/s
```

- 单目标低于多重陨星，高于法阵；群体靠三领域覆盖、牵引和黑洞聚集取胜。
- 领域武器不接元素/充能/站定，自身数值就是完整基线；武器升级与专属天赋是唯一成长来源。
- 高攻速下坍缩锁 2.5 秒限制黑洞常驻；基础 2.7 秒循环不受影响。满攻速 + 视界扩张约 56% 黑洞覆盖；若实机过强，优先加锁，不先砍黑洞伤害。
- Boss 免疫牵引与眩晕/定身，只吃伤害和有限减速；精英牵引/控制减半。
- 三张 L3 全选 + 武器满级是完整形态，需实机确认是否过强；优先调控制递减、坍缩锁和领域跳伤，不改单张卡的机制。

## 12. 实现交接

### 12.1 建议顺序

1. `src/game/data/domain.ts`：节奏、几何、经验表、升级表、状态类型/工厂。
2. `src/game/data/combatBalance.ts`：新增 `DOMAIN_DAMAGE` 伤害系数；`core/DamageMath.ts`：纯函数（领域跳伤、黑洞爆发/跳伤、斩击）。
3. `src/game/data/damageTypes.ts`：注册 `gravity`。
4. `types.ts`：`MageWeapon`、`GravityField`、`BlackHole`、`DomainWeaponState`、控制抗性可选字段。
5. `GameCore`：`mageWeapon`、领域状态、`startGame/resetGame` 参数、清理。
6. `core/DomainSystem.ts`：索敌、施放、领域跳伤、牵引/减速、坍缩、黑洞、XP、升级。
7. `MageSystem`：`mageWeapon === "domain"` 早退；`AttackSystem` 接入 `updateDomainWeapon`。
8. `EnemySystem`：领域牵引/减速；控制抗性递减；Boss/精英豁免。
9. `data/talents/domain.ts` + `talents/index.ts`：15 张卡与依赖。
10. `TalentSystem` / `codexData` / `DevPanel` / `GameUI`：卡池过滤、开始选择、教程分支、面板、图鉴。
11. `rendering/DomainRenderer.ts` 或 `draw.ts`：领域、连线、坍缩、黑洞、3 格指示。
12. 文档、CHANGELOG、`src/game/data/changelog.ts`、`docs/migration.md`、版本号。

### 12.2 数据所有权

- 节奏、几何、持续、经验、升级、卡面文案：`data/domain.ts` 与 `data/talents/domain.ts`。
- 伤害系数：`data/combatBalance.ts` 的 `DOMAIN_DAMAGE`。
- 纯伤害计算：`core/DamageMath.ts`，不在系统文件里内联新公式。
- 运行态：`DomainWeaponState`，每个 `GameCore` 一局一份；不增加全局可变状态。
- Core 不依赖 DOM/Phaser；UI 只通过命令与只读状态接入。

### 12.3 清理清单

- 收波：清空领域、黑洞、坍缩锁、斩击波次、控制抗性计时。
- 死亡/重开/返回开始：同上，并重置武器等级/经验/升级。
- 暂停/属性面板：冻结计时，不推进领域/黑洞/控制抗性。
- 教程：领域武器不进入传统法师教程，不写传统教程已看标记。
- DEV 跳波/清天赋：清理瞬态，不保留跨波黑洞。

## 13. 验收与验证

### 13.1 交付线

- `npm run typecheck` 通过。
- `npm run build` 通过。
- 默认不运行 Vitest/Playwright；若新增/修改使既有断言过期，在提交信息与 `docs/migration.md` 留痕，留待用户授权的测试批次。

### 13.2 受控验证点

1. 连续放 3 个领域 → 0.35 秒牵引 → 黑洞生成；3 个领域被消耗。
2. 黑洞在三点重心生成；半径、牵引、减速与配置一致。
3. 同一目标最多吃 2 个领域跳伤；第 3 个领域不额外跳伤。
4. 领域跳伤/黑洞跳伤无飘字；黑洞形成只弹一次数字。
5. 施法速度提升后循环加快；坍缩锁 2.5 秒仍生效，不出现永久黑洞。
6. 领域自然到期不坍缩；第 4 个领域替换最旧领域。
7. Boss 牵引 0、眩晕/定身免疫；精英牵引/控制减半。
8. 选择坍缩领域时，卡池没有元素/充能/星陨/双修/残域/相位等传统法师卡；选择法阵时没有领域卡。
9. 武器经验、等级、9 条升级正常；满级全拿。
10. 收波/死亡/重开/暂停/属性面板后无残留领域、黑洞或计时。
11. 3 领域 + 黑洞 + 150 敌人的帧时间与飘字数量可接受。
12. 三张 L3 全选时普通怪不会永久无交互；Boss 仍按免疫口径运行。

### 13.3 受控沙盒建议

实现后按项目现有 e2e 约定增加（仅在 DEV + MODE=e2e 暴露）：

- `?test=domain-max`：法师坍缩领域满级、全升级、木桩/敌群。
- `?test=domain-bh`：只保留领域与黑洞相关状态，便于观察牵引、坍缩和控制递减。

不把沙盒状态当作自然试玩结论；最终手感由用户实机确认。

## 14. 风险与待定

| 风险 | 处理 |
|---|---|
| 三张 L3 全选导致普通怪永久控制 | 控制递减 + 每张代价；Boss 免疫；实测后再调时长/抗性 |
| 高攻速下黑洞常驻 | 坍缩锁 2.5 秒；双星系统固定 0.8 秒且不吃视界扩张/坍缩理论 |
| 领域放在玩家脚下把敌人拉脸 | 落点避开玩家 48px；必要时选择次密集点 |
| 3 领域 + 黑洞群体伤害超模型 | 同目标最多 2 领域跳伤；黑洞总量按 2.95× 固定；实测再调 |
| 引力伤害吃护甲，后期高护甲敌人过肉 | 「重力碾压」无视 30% 护甲；必要时调 `DOMAIN_DAMAGE` 或破甲比例 |
| 新 `gravity` 类型影响图鉴/统计 | 只增加注册表条目与统计分项，不改现有元素抗性 |
| 与现有 `mageDomains` 命名冲突 | 新代码统一用 `gravityFields` / `blackHole`；「残域」只指元素残域 |
| 与 Boss 分支/上游版本冲突 | 本设计基于 v156；实现前再 fetch 并对版本号顺延 |
| 领域武器卡池过薄 | 15 张专属；旧表通用卡当前 `hidden`，不计入抽取；若实际抽取次数不足，再补 2–4 张增幅卡 |
